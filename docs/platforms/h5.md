# H5

```ts
interface H5CapabilityOptions {
  manifest?: NeoManifest | null;
  storage?: { prefix?: string; namespace?: string };
  input?: { target?: HTMLElement | null };
  resource?: { baseUrl?: string };
}

interface H5Capabilities extends CapabilityBundle {}

function createH5Capabilities(options?: H5CapabilityOptions): H5Capabilities;
```

- `storage.namespace` 缺省取 `manifest.name`，再缺省为 `game`；`prefix` 缺省为 `neo:`。
- `input.target` 用于独立使用；正常由 runtime 在 mount 后调用 `bind({ canvas })` 绑定到 canvas。
- `resource.baseUrl` 用于拼接资源 URL；H5 构建/dev 引导会注入 `import.meta.env.BASE_URL` / `'./'`。
- H5 实现基于 DOM：`localStorage`、`HTMLAudioElement`、Pointer Events、`fetch`、`document.visibilitychange`、`screen.orientation`。

能力语义见 [平台能力](../capabilities/README.md)；资源 key 见 [资源 key](../assets/keys.md)。
